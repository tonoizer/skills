# Tonoizer Agent Skills

Reusable agent workflow skills for GitHub Copilot and VS Code.

Install this extension to make all skills available as Copilot chat skills
without manually copying files.

## Included Skills

- **grill-me** — stress-test a plan or decision
- **implement** — build settled work as small verified slices
- **debug** — reproduce and fix defects
- **explain** — one-shot read-only explanation
- **teach** — adaptive learning through practice and feedback
- **readout** — interactive HTML guide from an investigation
- **code-review** — review a local diff, commit, or branch
- **resolve-conflicts** — finish a conflicted Git operation
- **create-pr** — prepare a reviewable pull request
- **babysit** — keep a PR merge-ready
- **split-to-prs** — divide work into coherent PRs
- **review-pr** — inspect and decide on an existing PR
- **release-pr** — prepare a release PR with version and changelog
- **ci-fix** — watch and repair GitHub CI failures
- **issue-triage** — classify the issue/PR queue
- **manager** — delegate to builder and reviewer agents
- **loop** — autonomous engineering loop
- **git-finish** — verify, stage, commit, push
- **repo-guardrails** — enforce AGENTS.md policy
- **worktree-agents** — isolated parallel agent work
- **humanizer** — remove AI writing tells
- **simplify** — simplify code without changing behavior
- **agent-browser** — browser automation for agents
- **find-skills** — discover installable skills
- **frontend-design** — polished UI design
- **deep-review** — root cause issue/PR analysis
- **maintainer-orchestrator** — multi-repo coordination

## Installation

Install the `.vsix` file locally:

```
code --install-extension tonoizer-agent-skills-0.1.0.vsix
```

Or use the VS Code command palette: **Extensions: Install from VSIX...**
